## Project Summary

In this project, I worked on a Student Performance dataset and built Machine Learning models to predict students' final grades.

I started by exploring and cleaning the dataset, selecting useful features such as study time, failures, absences, and previous grades. I then split the data into training and testing sets and trained two models: Linear Regression and Random Forest Regression.

Finally, I compared the models using MAE, RMSE, and R² Score and analyzed the important features affecting the predictions.

This project helped me understand the basic Machine Learning workflow and gave me practical experience with Python, Pandas, Matplotlib, Seaborn, and Scikit-learn.
